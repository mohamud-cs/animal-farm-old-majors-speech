# Animal Farm: Old Major's Speech

A personal web development project that presents Old Major's speech from Chapter 1 of George Orwell's *Animal Farm* as a web page. I'm building it in phases to practise front-end fundamentals and to learn how to manage a project with Git and GitHub.

**Status:** In progress (Phase 1: front end)

**Live site:** _coming soon_

## About the project

*Animal Farm* is a book I enjoy studying, and Old Major's speech is the moment the whole story starts. I wanted a project that would let me build a real web page from scratch, rather than only following tutorials. The goal is a clean, readable page that presents the speech clearly and links to a video of the original scene.

I'm starting with the front end and getting the structure and content right first, then adding the full speech across multiple pages.

## What I'm practising

- Writing structured, valid HTML
- Styling and laying out a page with CSS
- Making a page readable and accessible on different screen sizes
- Using Git and GitHub: committing small, meaningful changes and keeping a clear history
- Planning a project in phases, which is how I approach work in Agile teams

## Roadmap

**Phase 1: Front end (in progress).** Finish the structure, styling and responsive layout for the first page.

**Phase 2: Full speech.** Add the complete speech, split across several pages with navigation between them.

**Phase 3: Improvements.** Add interactivity with JavaScript, run an accessibility audit, and explore rebuilding the project with a modern framework such as Next.js and TypeScript.

## Run it locally

1. Clone the repository:
   ```
   git clone https://github.com/mohamud-brunel/animal-farm-old-majors-speech.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser. No installation or build step is needed.
